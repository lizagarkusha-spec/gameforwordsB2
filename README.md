# Word Court — Legal English B2

A lightweight, mobile-friendly English vocabulary game built from the supplied legal vocabulary worksheet.

## Play
Open `index.html` in a browser, or visit the GitHub Pages site once it is enabled. No build step or account is required. Progress is stored in the browser's local storage.

## Learning modes
- Quick round: multiple-choice meaning recall.
- Pairs: match English legal phrases with Ukrainian meanings.
- Court case: restore vocabulary in contextual sentences.
- Word detective: retrieve the English phrase from a Ukrainian clue.
- Word library: review the complete vocabulary set.

The activities use TEFL-style contextual presentation, retrieval practice, immediate feedback, and recycling across different task types. The set includes 55 entries from both supplied screenshots.
